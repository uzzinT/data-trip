# 데이터 여행사 (Data Trip)

통합과학2 **Ⅲ-1-02. 과학 기술 사회에서 빅데이터 활용** 수업용 웹 게임입니다. [데이터 구조대](https://github.com/uzzinT/data-rescue)의 두 번째 게임입니다.
학생은 여행 플래너가 되어 의뢰인의 조건(TPO)에 맞는 하루 여행을 데이터로 설계하고, 의뢰인이 여행을 다녀와 매긴 점수를 받습니다.

## 바로 해 보기

**학생용 주소: https://uzzint.github.io/data-trip/**

- 설치할 것 없이 `index.html`을 브라우저(크롬·엣지)로 열면 됩니다.
- 한 판(의뢰 3개)은 약 15~20분입니다.

## 게임 흐름

1. **의뢰서**: 의뢰인의 조건 읽기 (인원·예산·계단·이동 거리·식사·취향)
2. **데이터 탐색**: 지도·장소 데이터 표·날씨 데이터
   - 평점과 **믿을 수 있는 범위**(리뷰가 적을수록 넓어짐), 리뷰 원자료(작성일·내용)
   - 시간대별 혼잡도 (80 이상 = 매우 붐빔)
   - 시간대별 강수확률·체감온도 (60% 이상 비, 33℃ 이상 폭염)
3. **일정 짜기**: 오전 관광 · 점심 · 오후 관광 · 저녁 네 칸 채우기
4. **여행 · 후기**: 의뢰인이 경로를 따라 여행하며 일기를 남기고, 7개 항목으로 만족도(100점)와 별점 3개를 받음
5. **최종 보고서**: 생각 모음 복사, 보고서를 이미지(PNG)로 저장

## 빅데이터 개념

| 개념 | 게임 속 체험 |
|---|---|
| 데이터 → 정보 → 지식 | 리뷰·방문자 수·예보 → 혼잡도 그래프·평점 범위 → 일정 결정 |
| 데이터 양과 신뢰도 | 리뷰 6개 5.0점 vs 리뷰 1,500개 4.6점 |
| 검증되지 않은 데이터 | 리뷰 1개짜리 계정들이 사흘 사이에 몰아 쓴 광고성 리뷰가 달린 장소 2곳 |
| 사생활 침해 | 🔒 동의 없는 SNS·카드 결제·위치 기록 열어 보기 |
| 지나친 의존 | 🤖 평점 순으로만 고르는 AI 추천 코스 |

## 수업 내용 바꾸기

`index.html` 아래쪽 `<script>`의 **`PLACES`**(장소 데이터), **`CLIENTS`**(의뢰인·날씨·질문), **`STORY`**(대사)만 고치면 됩니다. 의뢰인을 바꾸면 `ideal`(모범 코스)도 맞춰 주세요. 페이지를 열 때 모범 코스가 100점인지 콘솔에서 자동 점검합니다.
